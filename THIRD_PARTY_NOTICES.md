The MIT grant applies to the original code in `pipeline/`, `analysis/GSE16710/code/R/`, `analysis/study_sources/code/R/` and `data/ledger/historical_builder.py`. Original documentation, project-generated aggregate tables and original metadata curation are offered under CC BY 4.0, as stated in README. Source accessions and source-reported factual metadata retain their provenance; this grant does not claim exclusive rights in those facts. No licence in this release overrides rights in any external resource or source dataset. The retained dependency lock describes externally licensed packages and does not relicense them.

Upstream resources include DoRothEA, PROGENy, Reactome, GO/QuickGO annotations and Matrisome definitions. This release does not distribute their source files, gene-set memberships or downloadable package archives. It distributes original code, metadata, aggregate family counts/reference descriptors and the retained feature-level S1 gate, retaining collection labels and feature identifiers to describe the analysis. Users reconstructing upstream analyses must obtain the exact frozen resources separately and observe their applicable version-specific terms.

In particular, a software-package licence is not a blanket grant covering every constituent network. Reactome website terms must not be substituted for the declaration attached to a particular archived release. No permission to redistribute an unlicensed third-party membership file is implied.

The project's non-commercial academic use does not restrict the MIT grant for its original code to non-commercial use. The grant neither claims ownership of external material nor changes external data-use conditions.

This release excludes article PDFs, private diagnostic errors, machine-specific custody logs, credentials and software dependency tarballs. It is not the entire study evidence archive.
