# Conditional references, anchor companions and matched quantification

This source collection extends the public analysis kernels with the original conditional-label, score-baseline, crossed-specification and matched-quantifier implementations and their saved-result readers. It identifies 151 sources: 124 newly supplied files and 27 byte-identical files reused from earlier public components. `SOURCE_GRAPH.json` gives the public location of each source, its original and public identities, and the recorded selection relationships.

Of these sources, 148 match the sealed study source archive. Three additional current sources were omitted from that archive but are identified by literal SHA-256 pins in included archived callers: the eleven-worker checkpoint continuation, its execution checker, and the closed-cache handoff helper. Their origin is distinguished in the graph. This repairs source availability without inventing a historical zero exit or rerunning any accepted calculation.

## Read-only verification and environment

From the repository root:

```sh
python -I -B pipeline/references.py verify
python -I -B pipeline/sources.py verify
python -I -B pipeline/anchor.py verify
python -I -B pipeline/ledger.py verify data/ledger
```

The verification entry requires Python 3.12 or later and only its standard library. It checks published bytes, the 151-source mapping, explicit substitutions, and the original digest bindings for the three additional sources. It does not import the scientific modules, call R, inspect raw data, fit models or generate labels. Record the Git tag/commit and verification output. Release QA additionally parses the 107 selected R and 44 Python sources without evaluating them. Parsing is not package restoration or numerical reproduction.

The R source requirements and original version checks remain authoritative for their own branches. The anchor dependency lock is not a substitute for the separate Linux reference and matched-quantifier environments. No universal dependency-lock or full environment restoration is claimed for this source collection. Original configuration/seed checks, software versions, allocation labels, native process receipts and successful output identities must be supplied together for any future run or checkpoint reuse.

## Remaining execution dependencies

Raw inputs, prepared scientific objects, third-party memberships, complete environment archives and machine-specific receipts remain external. The static inventory records unresolved literal names rather than silently treating them as supplied. Some are usage placeholders (`THIS.R`), generated worker aliases (`worker.R`, `summary.R`) or partial filename expressions. Others refer to deployment/cache helpers outside this selection. Dynamic aliases need their actual run manifests; this inventory alone cannot resolve them.

The public layout separates retained source and metadata (`analysis/`), accepted aggregate results (`data/derived/`), fixed report outputs (`expected/`) and new local report output (`output/`). A future raw-to-result reconstruction must use separate immutable raw inputs, writable intermediates, fresh derived-output directories and input/code/environment-bound checkpoints. No accepted outputs or scientific fits were rerun to prepare this release. Complete clean-machine reconstruction and independent PSS phenotype-linked holdout validation remain separate unfinished requirements.
