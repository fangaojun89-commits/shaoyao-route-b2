## Data and standardized reanalysis

We specified a separate analysis of PRJNA886048 to characterize the transcriptional response to baclofen in injured mouse spinal tissue. The source reports 12 female C57BL/6J mice randomly assigned to baclofen or saline, with six mice per group and spinal tissue collected seven days after injury. The archive contains 12 distinct BioSamples and one paired-end sequencing run per sample. The mouse is the biological unit; group-specific replicate numbers do not define matched animals. The fixed unpaired contrast is baclofen minus saline.

The article reports an age range of 8–12 weeks, RIN values above 7 for all samples and sequencing on one S1 lane. We retain the malformed archive age string separately rather than assigning an individual age to each mouse. The retained sample map contains neither individual numeric RIN values nor library-preparation batch labels; these are not covariates in the fixed model. A shared sequencing lane does not establish the absence of other technical variation. This source provides pharmacological context in an injured spinal system. It does not include an uninjured comparator or a reusable individual spasticity measurement linked to each library. Published findings were inspected during source retrieval, so this analysis is retrospective and is not an outcome-protected validation set.

Complete paired FASTQ files were verified against the deposited ENA MD5 values. The standardized pipeline uses fastp 0.20.0 for paired adapter detection and quality-based trimming from both the 5′ and 3′ ends, using one-base windows with a mean Phred quality threshold of 20. The window width does not specify a fixed number of bases to remove. Read filtering uses a minimum retained length of 37 bases, a Q15 qualification threshold, a maximum of 40% unqualified bases and five ambiguous bases per read; poly-G trimming uses a minimum tail length of ten bases. The exact command is retained. These choices operationalize the reported processing description; the original command was unavailable. No deduplication, overlap correction or additional poly-X trimming is specified.

Quantification uses kallisto 0.46.1 and a reused k=31 index containing 146,190 unique cDNA and ncRNA targets from GRCm39/Ensembl release 107, mapped to 53,511 genes. The reference release is an explicit reanalysis choice because the source does not identify its Ensembl release. Targets absent from the supplied sequence files remain documented as unavailable. Native output retains 46 transcripts shorter than k=31 with zero estimates; those entries do not establish biological absence. Orientation is checked on deposited read prefixes before full-library quantification. Existing two-window checks are reused for the first two inspected libraries; subsequent libraries use their fixed first 250,000 pairs. An orientation pattern inconsistent with the unstranded setting requires resolution before quantification, independently of downstream effect estimates.

## Gene and program inference

The complete 12-library cohort will be aggregated with tximport. Raw transcript estimates, abundance and effective lengths are retained separately. The specified primary gene analysis uses lengthScaledTPM count-scale estimates, TMM normalization and a robust edgeR quasi-likelihood contrast for baclofen minus saline, without an additional transcript-length offset. Eligible genes must satisfy filterByExpr and CPM ≥1 in at least six libraries. Limma-voom with robust empirical Bayes variance moderation supplies a same-data gene-method sensitivity and nominal 95% gene-effect intervals. Gene-level BH adjustment is performed separately within each method. These inputs are estimated count-scale values rather than observed integer fragment counts. Quantification uses no kallisto bootstrap replicates; transcript-assignment uncertainty is therefore not propagated through these gene models. Sample quality summaries and multidimensional scaling will be reported for the full cohort; treatment-effect significance is not an exclusion criterion.

Competitive program membership tests use CAMERA on the retained voom object, a fixed inter-gene correlation of 0.01 and 10–500 expressed members per term. All filtered genes form the background. Reactome 97 uses the retained strict one-to-one human–mouse mapping; native mouse PROGENy 1.34.0 and DoRothEA 1.23.0 A/B retain their frozen footprints. Complete coverage tables include untested terms. BH adjustment is performed separately within each collection for the fixed contrast. For weighted footprints, unsigned membership direction is reported separately from signed activity.

Signed PROGENy and DoRothEA scores are specified using decoupleR ULM with the retained target weights, center=FALSE and the complete filtered expression background. Eligible terms require 10–500 expressed targets with nonzero weights. Each per-library score then enters an ordinary unpaired six-versus-six linear contrast, with ten residual degrees of freedom, a two-sided t test, a nominal 95% confidence interval and collection-wise BH adjustment. Numerically degenerate score variance is reported without inferential P values or intervals. The ULM gene-regression P value is not used to test the treatment effect.

## Comparison with retained Route B2 results

All 14 PROGENy programs will be compared with nine core context columns and ten prespecified companion columns from the retained Route B2 outputs. Each source keeps its original effect scale, interval definition and testing family. The comparison reports finite paired denominators, concordant and opposite signs, exact zeros, missing values and descriptive Spearman correlations across the complete paired panel, without significance-based selection. It does not pool effect sizes or calculate a P value for cross-source agreement. Shared samples, controls and alternative specifications are explicitly identified. Complete gene, CAMERA and signed-activity results remain available alongside this focused panel; the comparison does not reopen S1 or imply preparation equivalence, clinical antispastic efficacy or independent PSS phenotype validation.

The target of inference is the treatment-associated response of bulk injured spinal tissue at day 7. Changes in tissue composition and changes within cells both contribute to this measurement; the bulk contrast alone cannot separate them. Cross-source agreement will therefore describe program-level correspondence between the retained study contexts. It will not establish a cell-intrinsic mechanism, normalization toward uninjured tissue, or equivalence between an acute spinal injury response and chronic post-stroke spasticity. The deposited cohort is female-only, so this analysis cannot estimate treatment-by-sex differences.
